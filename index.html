Conectar calendario
Recomendado para Zcal. En tu sheet, columnas (en cualquier orden):
fecha · hora · cliente · link · notas
(también acepta start, name, email, url)

Setup: En la sheet → Archivo → Compartir → Publicar en la web → tipo CSV. Copia esa URL aquí.
Zapier: trigger "New Booking in Zcal" (o Google Calendar) → action "Create Spreadsheet Row".
Google Calendar: Ajustes → tu calendario → Integrar el calendario → copia la "Dirección secreta en formato iCal".
Zcal: exporta el feed iCal de cada calendario.
Pasa por un proxy CORS público (corsproxy.io) — para info sensible usa la opción Sheet.

Sincronización con GitHub

CONFIGURACIÓN · v1.5
Token fine-grained con acceso solo al repo de datos. Generar →
Repo aparte solo para datos. Si no existe, creálo en GitHub primero (puede estar vacío).
¿Cómo funciona? Tus datos siguen viviendo en este navegador (localStorage). Cada vez que hay cambios, el OS los sube en silencio a tu repo privado de GitHub. Si abrís el OS en otro dispositivo, descargás los datos desde ahí. El token solo necesita permiso Contents: Read & write sobre ese repo.
